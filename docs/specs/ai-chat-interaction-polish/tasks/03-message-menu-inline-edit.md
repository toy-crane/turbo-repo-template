# 03 — 메시지 메뉴와 인라인 편집

## Outcome

사용자는 사용자 말풍선을 길게 눌러 복사하거나 그 자리에서 편집한다. AI 답변은 현재 작업
영역을 유지하되 더 단단한 아이콘과 크기가 변하지 않는 복사 완료 상태를 보여 준다.

## Blockers

None.

## Acceptance criteria

- [x] 사용자 메시지 아래의 상시 복사·편집 아이콘을 제거하고 사용자 말풍선 전체를 HeroUI
  Native `PressableFeedback` 표면으로 만든다.
- [x] 사용자 말풍선을 짧게 누르면 레이아웃을 바꾸지 않는 약한 크기와 밝기 피드백만 주고,
  메시지나 메뉴 상태를 바꾸지 않는다.
- [x] 사용자 말풍선을 길게 누르면 햅틱과 함께 HeroUI Native `Menu` popover를 연다. 메뉴는
  말풍선 가까이에 놓이며 화면 경계와 겹치면 안쪽으로 위치를 조정한다.
- [x] 메뉴는 약한 overlay 위에 `복사하기`, `수정하기`를 공용 `Icon`과 함께 이 순서로
  표시한다. 바깥을 누르거나 시스템 뒤로가기를 실행하면 작업 없이 닫힌다.
- [x] 메뉴와 `PressableFeedback`은 사용자 메시지에만 적용한다. AI 답변을 길게 눌러 같은
  메뉴를 열지 않는다.
- [x] 생성 중에도 `복사하기`는 실행할 수 있고 `수정하기`는 비활성화한다.
- [x] 사용자 메시지를 복사하면 메뉴를 닫고 성공 햅틱과 `복사됨` 접근성 알림을 보낸다.
  체크 아이콘, 문구와 토스트를 새로 표시하지 않는다.
- [x] 길게 누르기 어려운 VoiceOver와 TalkBack 사용자가 접근성 작업으로 `복사하기`와
  `수정하기`를 직접 실행할 수 있다.
- [x] 모든 사용자 메시지에서 `수정하기`를 제공한다. 선택한 말풍선이 같은 자리의 여러 줄
  입력, `취소`, `보내기`로 바뀌고 입력 포커스가 그 편집기로 이동한다.
- [x] 한 번에 한 메시지만 편집한다. 편집 중에는 이후 대화를 그대로 표시하고 하단 입력창의
  위치와 높이를 유지한 채 입력과 전송을 비활성화한다.
- [x] `취소`는 원문과 이후 대화를 유지한다. `보내기`는 공백뿐인 내용을 막고, 선택한 사용자
  메시지와 그 뒤의 모든 메시지를 제거한 뒤 고친 메시지를 새 마지막 메시지로 보낸다.
- [x] 편집 중이거나 취소할 때는 이후 대화를 제거하지 않는다. 생성 중에는 편집을 시작하거나
  확정할 수 없다.
- [x] 편집을 닫거나 보낸 뒤 포커스를 맥락을 잃지 않는 위치로 돌려보내고, Dynamic Type에서
  인라인 편집기와 이후 내용이 입력창에 가리지 않는다.
- [x] AI 답변은 기존 작업 영역과 마지막 답변 다시 생성 범위를 유지한다. 작업 아이콘은
  20 크기와 semibold에 해당하는 시각적 무게를 사용한다.
- [x] AI 답변 복사에 성공하면 같은 자리의 복사 아이콘을 2초 동안 체크 아이콘으로 바꾼다.
  작업 줄의 너비와 메시지 높이는 바뀌지 않으며 접근성 상태도 `복사됨`을 알린다.
- [x] iOS는 SF Symbols, Android는 같은 의미와 무게의 Material Symbols를 공용 `Icon`
  경계에서 사용한다. 새 아이콘 폰트나 공통 SVG 세트를 추가하지 않는다.

## Constraints

- 하단 입력창을 편집기에 재사용하거나 `메시지를 고치는 중` 표시를 추가하지 않는다.
  편집 대상과 편집 초안은 하단 입력 초안과 분리한다.
- 이후 대화는 편집 `보내기`를 실행하는 순간에만 잘라 낸다. 제거한 메시지의 갈래, 버전과
  복구 저장소를 만들지 않는다.
- 메뉴는 iOS 네이티브 컨텍스트 메뉴나 말풍선 미리보기를 복제하지 않는다. HeroUI Native
  `Menu`의 popover, collision 처리와 overlay를 사용한다.
- 아이콘 변경은 채팅에서 필요한 의미만 공용 `Icon`에 추가하거나 조정한다. 프로젝트 전체
  아이콘 체계를 바꾸지 않는다.
