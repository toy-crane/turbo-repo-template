# 온보딩 입력 제목 명세

## 목표

닉네임과 아이디를 정하는 두 화면의 큰 본문 제목을 같은 문장 형식으로 맞춘다. 각 화면에 들어가면 입력창에 바로 포커스해 사용자가 곧바로 값을 바꿀 수 있게 한다.

## 확인한 현재 상태

- 닉네임과 아이디 입력창은 모두 화면에 들어가면 자동으로 포커스하며 키보드를 연다.
- 두 화면은 같은 본문 제목 스타일을 사용한다.
- 닉네임 화면의 제목은 `닉네임을 정해 주세요`다.
- 아이디 화면의 제목은 `사용할 아이디를 입력해 주세요`다. 닉네임 화면과 문장 형식이 다르고, 확인한 iPhone 화면에서는 두 줄로 표시된다.
- 닉네임 화면은 온보딩의 첫 화면이라 네이티브 헤더가 없다. 아이디 화면은 닉네임 화면으로 돌아갈 수 있도록 최소 뒤로가기 버튼이 있는 네이티브 헤더를 사용한다. 이 차이 때문에 두 화면의 본문 시작 위치가 다르다.

## 확정한 동작

- 큰 본문 제목은 `항목 + 을/를 정해 주세요` 형식으로 통일한다.
- 닉네임 화면은 `닉네임을 정해 주세요`를 유지한다.
- 아이디 화면은 `아이디를 정해 주세요`로 바꾼다.
- 두 화면 모두 들어갈 때 해당 입력창에 자동으로 포커스하고 키보드를 연다.
- 두 화면은 높이가 같은 네이티브 헤더 틀을 사용한다.
- 첫 단계인 닉네임 화면의 헤더에는 뒤로가기를 두지 않는다.
- 아이디 화면의 헤더에는 닉네임 화면으로 돌아가는 뒤로가기를 유지한다.
- 단계 표시와 진행 상황은 추가하지 않는다.
- 입력 라벨, 자리 표시자, 버튼 문구, 검증과 저장 흐름은 바꾸지 않는다.

## 완료 조건

1. 닉네임 화면의 큰 본문 제목이 `닉네임을 정해 주세요`로 보인다.
2. 아이디 화면의 큰 본문 제목이 `아이디를 정해 주세요`로 보인다.
3. 각 화면에 들어가면 입력창이 포커스되고 키보드가 열린다.
4. 두 화면의 큰 본문 제목이 같은 세로 위치에서 시작한다.
5. 닉네임 화면의 헤더에는 뒤로가기가 없다.
6. 아이디 화면에서 네이티브 뒤로가기를 사용할 수 있다.
7. 아이디 화면에서 닉네임 화면으로 돌아가도 두 입력값을 유지한다.

## 제외할 범위

- 온보딩 단계 수와 순서 변경
- 닉네임 화면에 뒤로가기, 취소 또는 닫기 추가
- 단계 표시와 진행 상황 추가
- 입력 규칙, 아이디 사용 가능 여부 확인과 저장 방식 변경
- 제목의 글자 크기, 굵기와 간격 변경

## 남은 위험

- 큰 글자 크기에서는 짧아진 제목도 줄바꿈할 수 있다. 두 문구가 같은 문장 형식을 유지하면 줄 수까지 항상 같을 필요는 없다.
