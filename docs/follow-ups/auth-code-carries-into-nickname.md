# 인증 코드가 닉네임 입력란으로 넘어간다

**Symptom**: 6자리 인증 코드를 채워 온보딩으로 자동 전환된 뒤 닉네임 입력란에 같은 6자리 값이 들어가 있다.

**Observed evidence**: 2026-08-14 iOS Simulator의 Development Build에서 `agent-device fill`로 인증 코드 `104901`을 입력했다. 닉네임 화면으로 전환된 직후 접근성 트리가 닉네임 text field 값을 `104901`로 보고했고 실제 스크린샷에서도 같은 값과 커서가 보였다.

**Suspected cause**: 인증 코드의 마지막 입력이 검증과 화면 전환을 시작한 뒤 새로 포커스된 닉네임 입력란에도 전달되는 것으로 보인다. `agent-device fill`의 입력 방식에서만 생기는지 실제 키보드 입력에서도 생기는지는 아직 확인하지 않았다.

**What was tried**: 전환 직후 접근성 snapshot과 screenshot을 각각 확인해 접근성 값만 남은 현상은 아니라는 점을 확인했다. 이번 Uniwind 스타일 작업에서는 인증 코드 제출이나 온보딩 포커스 코드를 바꾸지 않았다.

**Proposed next step**: 새 계정에서 인증 코드를 한 자리씩 실제 키보드로 입력해 다시 확인한다. 재현되면 인증 검증을 시작할 때 OTP 입력을 즉시 잠그거나 포커스를 해제하고, 닉네임 화면의 진입 포커스가 이전 키 입력을 받지 않도록 전환 시점을 점검한다.
