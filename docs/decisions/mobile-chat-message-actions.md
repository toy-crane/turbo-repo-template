# 모바일 채팅 메시지 동작

## 결정

- 완료된 AI 답변 아래에는 `답변 복사`와 `답변 다시 받기` 아이콘 줄을 둔다. 답변을
  기다리거나 받는 동안에는 이 줄을 보여 주지 않는다.
- 답변 복사는 서버에서 받은 Markdown 원문 전체를 클립보드에 넣는다. 다시 받기는
  해당 답변과 그 뒤의 메시지를 버리고 같은 자리에서 답변을 다시 만든다. 별도 확인은
  받지 않는다.
- 사용자 메시지를 길게 누르면 `복사`와 `수정` 메뉴를 연다. 한 번 누르는 것은 아무
  일도 하지 않으며, 사용자 메시지 본문 선택은 끈다.
- 수정은 원문을 입력창에 넣고 해당 메시지부터 뒤의 메시지를 흐리게 보여 준다. 수정해
  보내면 그 메시지부터 대화를 다시 시작한다. `수정 그만두기`를 누르면 대화와 수정 전
  초안을 복원한다.
- 답변을 기다리거나 받는 동안 전송 버튼 자리는 `답변 그만 받기`로 바뀐다. 중지하면
  받은 데까지 답변으로 남기고 별도 중지 표시는 붙이지 않는다.
- 요청이 실패하면 기존 메시지를 남기고 오류 옆의 `다시 시도하기`로 같은 질문을 다시
  보낸다.
- 사용자 메시지와 AI 답변은 같은 본문 역할을 쓴다. 답변 동작 버튼은 16px 아이콘을
  담은 28px 버튼 두 개로 붙여 놓고, 위아래 누르기 범위만 `hitSlop`으로 6px씩
  넓힌다.

## 경계

- AI 답변 본문은 시스템 텍스트 선택을 유지한다. 사용자 메시지에는 앱의 길게 누르기
  메뉴를 붙인다. AI 답변에서 선택한 구절로 시작하는 동작은
  [모바일 Side chat](mobile-side-chat.md)을 따른다.
- 답변 평가, AI 답변 수정, 복사 성공 알림, 여러 메시지 선택, 되돌린 대화 보관은 이
  동작에 포함하지 않는다.
- 메시지 동작은 현재 대화 수명을 따른다. 화면을 나가서 버린 대화나 앱을 다시 연 뒤의
  대화를 복구하지 않는다.
- 메시지 표현, `Thinking`, 입력 영역과 최신 메시지 이동은
  [모바일 AI 채팅 표현](mobile-ai-chat-rendering.md)을 따른다.

## 이유

AI 답변의 자주 쓰는 동작은 항상 보이는 작은 아이콘 줄에 두고, 사용자 메시지의
동작은 길게 누르는 메뉴에 두면 본문을 읽는 흐름을 유지하면서 역할을 구분할 수 있다.
수정, 다시 받기와 다시 시도는 모두 대화를 다시 시작하는 지점만 다르므로 같은 채팅
상태 경계에서 처리한다.

## 재검토 조건

- 대화를 저장하거나 되돌린 버전을 갈래로 보관할 때
- 사용자 메시지의 텍스트 선택과 길게 누르기 메뉴를 함께 제공해야 할 때
- 메시지 동작이 많아져 아이콘 줄이나 길게 누르기 메뉴에서 찾기 어려워질 때
- 잘못 누른 다시 받기로 대화를 잃는 문제가 사용자 검증에서 반복될 때

## 계속 제외하는 대안

- 되돌리기 전 확인창: 대화 흐름을 매번 끊는다. 저장된 대화나 복구 요구가 생길 때
  다시 검토한다.
- 사용자 메시지 안에 편집 입력창 두기: 목록과 키보드 경계를 복잡하게 만들고 기존
  입력창의 높이 조절과 전송 검사를 다시 구현해야 한다.
- 복사 성공 알림: 클립보드 동작마다 화면 알림을 더한다. 사용자가 복사 결과를 알기
  어렵다는 문제가 확인될 때 검토한다.
